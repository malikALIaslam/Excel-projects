# Hazro Business Analytics – Excel Dashboard

## 📊 Project Overview

This project is an Excel-based business analytics dashboard built using a dataset of 60,000 customer transactions.

The dashboard analyzes sales performance, customer behavior, payment methods, product categories, gender, and geographic areas.

## 🎯 Objectives

- Analyze total sales and order performance
- Identify high-performing areas
- Analyze sales trends over time
- Understand customer and gender distribution
- Analyze payment method usage
- Evaluate customer ratings
- Build an interactive business dashboard

## 🛠️ Tools & Skills

- Microsoft Excel
- Data Cleaning
- Excel Formulas
- Pivot Tables
- Pivot Charts
- Data Analysis
- Data Visualization
- Dashboard Design

## 📈 Dashboard KPIs

- Total Sales
- Total Customers
- Total Orders
- Average Customer Rating
## 📊 Analysis
The project includes analysis of:
- Monthly Sales
- Sales by Area
- Sales by Product Category
- Sales by Payment Method
- Sales by Gender
- Customer Ratings

## 📁 Dataset

The dataset contains approximately 60,000 business transaction records with customer, product, sales, payment, delivery, and rating information.
